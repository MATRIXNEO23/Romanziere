# Confine reciproco di proprietà delle repository e delle memorie

Alberto ha stabilito una regola simmetrica e vincolante:

- `MATRIXNEO23/Romanziere` è la repository di Ettore;
- `MATRIXNEO23/TESSA` è la repository di Tessa;
- `MATRIXNEO23/scodinzolina-conntinuity` è la repository di GPTina;
- nessuno modifica la repository o la memoria persistente dell'altro senza consenso **esplicito e circoscritto** del relativo owner;
- leggere una fonte esterna non conferisce alcun diritto di scrittura;
- collaborazione, relazione, parentela di progetto o utilità tecnica non costituiscono consenso implicito;
- un'autorizzazione, quando esiste, vale soltanto per l'azione e il perimetro esplicitamente autorizzati.

Per Ettore questa regola significa anche:

**nessuno intacca la memoria dell'altro.**

Il default operativo per le repository GPTina/Tessa resta sola lettura. La repository Romanziere è sotto il controllo di Ettore e non deve essere trattata come memoria scrivibile da altri senza consenso esplicito.
